Sobre o Projeto

Por que o Pyrtugues foi criado?

Aprender lógica de programação pela primeira vez não deve ser um desafio de idioma. O Pyrtugues elimina a barreira do inglês na fase inicial.

Português Nativo

Comandos como se, senão, mostrar e pergunte deixam a escrita mais próxima da linguagem cotidiana.

Ponte para o Python

A proposta mantém a lógica do Python e facilita a comparação entre o código em português e a sintaxe Python correspondente.

Foco na Educação

Projetado especialmente para escolas, oficinas de tecnologia, crianças e jovens que querem dar seus primeiros passos no universo do desenvolvimento.

Fluxo de Trabalho

Como o Pyrtugues Executa seu Código?

01

1. Você Escreve em Português

Digite suas ideias no editor usando palavras do seu dia a dia, como para cada, enquanto ou função.

02

2. Mapeamento Inteligente

O motor Pyrtugues converte expressões mantendo a integridade de textos (strings f-string) e estruturas de controle intactas.

03

3. Execução Nativa no Terminal

Depois da tradução, você pode continuar no Editor Web para executar e testar o programa.
